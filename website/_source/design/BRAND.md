# Brand rules

## Name
TheDigiCiti (one word, capital T, D, C).

## Palette — dusk
- Sky: `#0c0f2c` → `#2a2862` → `#73467c` → `#d9814f` → `#f3bd7c`
- Cream text: `#E1E0CC` (primary), `#DEDBC8` (buttons), muted `rgba(225,224,204,.7)`
- Gold (rent, coin): `#f6c445`, light `#fbdb81`
- Growth green: `#8fd65a`
- Night UI (app, story): `#0b0c12`, `#161826`, `#1e2130`

## Type
- Landing: Almarai (400/700) + Instrument Serif italic for accents
- App and story: Inter (design system)

## Motion
- Page changes: sky fade via `part-transitions.js`, ~0.5s out / ~0.8s in
- Inside the story: gold coin wipe between chapters
- Easing: `cubic-bezier(.16,1,.3,1)` for reveals, `cubic-bezier(.55,0,.25,1)` for camera moves
