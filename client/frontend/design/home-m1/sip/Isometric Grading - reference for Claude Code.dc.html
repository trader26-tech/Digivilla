Isometric plot — grading

Stage 2 of the ladder — the buyer owns the plot and is levelling it. Same base as the plot and villa; a bulldozer has cleared the front-right half down to flat earth, the back-left half is still meadow. Hand this whole file to a coding agent. Previous stage: the empty plot.

What this asset is

  • The plot after purchase, mid-grading. Base plinth and soil skirt are byte-identical to the plot and villa. The grass top is split at a = 0.42: everything at higher a (front-right) is flat earth #9a6a3f; the meadow keeps its clumps, one tree and a bush. The split is a jittered polyline, stroked #3f7a20, so it reads as a cut sod edge.
  • What reads as "being levelled": twin tread marks running from the sod edge to the machine, sod and topsoil heaps at the front corner, a fresh stump where the second tree stood, a drying puddle where the pond was, and the dozer itself with an earth mound against the blade.
  • The board is gone — it has been bought. No fence, no structures yet. Next stage: Isometric Construction (foundation → walls → villa).

The bulldozer

  • Built entirely from axis-aligned iso boxes. A box spans tile coords a0..a1 × b0..b1 and heights h0..h1 (px). Its three visible faces: top at h1; the +a face (lit); the +b face (shaded). Corner (a,b,h) → (410 + (a−b)·311.8, 70 + (a+b)·180 − h).
  • Parts, back-to-front: far track → hull → cab (glass box, yellow roof) → exhaust → near track → push arms → blade → earth mound. Machine yellow #f6c445 / #dc9a1f / #a86b12 (the gold-coin ramp), tracks #3f424d / #2b2e3a / #232634, glass #3a5f7a / #2f4f66, blade steel #b0b6bd / #9aa0a7 / #7c8189.
  • Motion: the hull group idles on a 0.5s rumble (sub-pixel translate), the blade group on a 1.6s blade bob, and three dust ellipses cycle a 2.2s puff with staggered delays. Transforms only — geometry is never rotated or skewed.

Paint order

  • Plinth → soil skirt → edge bands + fringe → full earth top + earth boundary → tread marks → meadow polygon + sod stroke → mowing stripes → scattered props sorted by a + b → dozer group → dust.
  • Strokes only for parcel boundary and sod edge. Flat polygons and ellipses; no gradients.

Reuse

  • Copy the <svg> block plus the three @keyframes. For a static board tile drop the animation styles — the silhouette alone reads.
  • On a grid tile: <g transform="translate(TX,TY) scale(S) translate(-410,-250)"> — same wrapper as the plot and villa.
  • To animate progress, move the sod edge a from 0.42 toward 0 and the dozer with it; at a = 0 the whole top is earth and the construction stage begins.
