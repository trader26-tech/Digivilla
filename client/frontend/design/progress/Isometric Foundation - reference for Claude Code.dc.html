Isometric plot — foundation

Stage 3 of the ladder — the plot is level and green again; the villa footprint has been dug out, boxed in timber formwork, and the concrete slab is being poured. Hand this whole file to a coding agent. Previous stage: grading.

What this asset is

  • The plot after grading, at the foundation pour. Base plinth, soil skirt, grass top and boundary stroke are byte-identical to the plot parcel — the meadow has been re-seeded flat, so the whole top is grass again. Only the footprint is disturbed.
  • Footprint: pit a,b ∈ [0.2, 0.8], 14px deep, showing the two far inner walls (soil, lit/shaded) and a compacted hardcore floor. Timber formwork boxes the pit rim on all four sides with stakes outside it. The slab a,b ∈ [0.235, 0.765] rises from the floor to 6px above grade; its back half is set (#b0b4ba), its front half is fresh pour (#8e939a) with a breathing sheen. Nine rust starter bars stand on a 3×3 grid where the villa's columns will land.
  • Site props: a mixer truck parked along the +a edge (cab facing +b, octagonal drum with a dark stripe, hopper aft, steel chute running straight in −a onto the wet half), a wheelbarrow at the front-left corner, a stack of cement bags at the back-right, a sand heap and a gravel heap on the back-left, a worn access track from the +a edge. All planting has been cleared — no trees, bushes, clumps or flowers; the lawn is a clean mown surface.
  • Next stage: Isometric Construction (walls rise from the starter bars) → villa.

Geometry rules

  • One fixed 2:1 isometric diamond: (a,b,h) → (410 + (a−b)·311.8, 70 + (a+b)·180 − h). Height is a vertical offset only; depth is a negative height. Never rotate or skew geometry.
  • Every solid is an axis-aligned iso box: top face at h1, +a face lit, +b face shaded — one hue, three values. The pit is the inverse: floor at −D, and only the a = a0 and b = b0 inner walls are visible.
  • Concrete #b0b4ba / #9aa0a7 / #7c8189 (set) and #8e939a (wet); timber #c9a97a / #a97140 / #8a5a2f; rebar #a86b12 over #7d5027; machine yellow #f6c445 / #dc9a1f / #a86b12; hardcore #6b6157.

Paint order

  • Plinth → soil skirt → edge bands + fringe → grass top + boundary → mowing stripes → access track → everything else sorted by a + b: back props → pit floor → far inner walls → back formwork → slab (set half, wet half) → front formwork + stakes → starter bars → front props → live layer (sheen, chute drip).
  • Strokes only for the parcel boundary. Flat polygons and ellipses; no gradients.
