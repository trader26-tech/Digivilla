Isometric plot parcel

Stage 1 of the ladder — the empty grass plot a broker pitches before anything is built. Same base as the villa; only the structures differ. Hand this whole file to a coding agent.

What this asset is

  • The Plot tier (₹10L, 100% equity). Base geometry — plinth, soil skirt, grass top, boundary stroke — is byte-identical to the villa parcel, so the two sit side by side on the same grid with no seam.
  • No fence, no paths, no structures. What reads as "empty land": a darker mown patch, a worn dirt patch, faint mowing stripes, two-tone grass clumps, wildflower clusters (cream, lavender, pale yellow, pink), two round-canopy trees at the back corners, a small pond with reeds and lily pads, four rounded bushes with soft ground shadows, two stones, and a wooden FOR SALE board on a post at the front-right corner. The board text is the one place a skewY(-30) is allowed — it lays type onto the lit face; geometry itself is never skewed.
  • Progression: plot → (add scaffold + shell from the construction reference) → villa. Keep the base; swap only what sits on the grass.

The projection (this is the part agents get wrong)

  • One fixed 2:1 isometric diamond. Half-width W = 311.8, half-height H = 180, grass top centred at (410, 250). Corners top/right/bottom/left = (410,70) (721.8,250) (410,430) (98.2,250).
  • Place anything on the grass with tile coords a, b ∈ [0,1]: x = 410 + (a − b)·311.8, y = 70 + (a + b)·180. Height is a pure vertical offset (subtract from y). Never rotate, never skew.
  • Every solid (shrub, stone) is three polygons: top diamond, right face lit, left face shaded — one hue, three values.
  • Scatter tufts with a seeded generator and sort by a + b ascending before painting; don't hand-place them.

Paint order

  • Plinth sides → soil sides → soil shadow → grass edge bands + fringe → grass top → boundary stroke → ground patches → tufts, shrubs, stones (sorted back-to-front) → sign post → board → board text slabs.
  • Strokes only for the parcel boundary. No gradients, no shading strokes.
