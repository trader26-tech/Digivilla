Isometric plot — steel frame

Stage 4 of the ladder — the slab has cured and the steel goes up: columns on the 3×3 grid, beams tying them at two levels, a scaffold tower and a crane lifting the last beam. Hand this whole file to a coding agent. Previous stage: foundation.

What this asset is

  • The plot after the foundation: formwork struck, slab fully set (#b0b4ba) with control joints, the pit backfilled so the slab sits 6px proud of the lawn. Base plinth, soil skirt, grass and boundary are byte-identical to the earlier stages.
  • Steel: nine H-columns on the a,b ∈ {0.32, 0.5, 0.68} grid, 120px tall, each on a square base plate. Primary beams run in a at levels 60 and 120; secondary beams run in b at the same levels. The front-right bay's top beam is still missing — it hangs from the crane hook. Steel is one hue, three values: #c9ced4 / #9aa0a7 / #6f7580; base plates and bolts #5d6170.
  • Site: a tower crane on the −a edge at a=0.08, b=0.34, clear of the frame silhouette (lattice mast, jib running toward the slab, counterweight, hook cable, swinging beam), a 2-lift scaffold tower with a plank deck on the +b side, a rack of pipes on the grass near the +a edge, a site container at the back-right, a wheelbarrow, and the worn access track. No planting.
  • Next stage: villa — the finished house, final stage of the ladder.

Geometry rules

  • One fixed 2:1 isometric diamond: (a,b,h) → (410 + (a−b)·311.8, 70 + (a+b)·180 − h). Height is a vertical offset only. Never rotate or skew geometry.
  • Every member is an axis-aligned iso box (top, +a lit, +b shaded). Columns are boxes 0.018 wide; beams are boxes 0.012 wide and 6px deep. Crane lattice is a thin box with lighter diagonal slats on the two visible faces.
  • The viewBox grows upward (0 -300 820 940) to hold the crane; the parcel stays at the same coordinates, so it still drops onto the grid with the same wrapper.

Paint order

  • Plinth → soil → edge bands + fringe → grass + boundary → stripes → track → everything else sorted by a + b of its footprint: crane base + mast → container → slab → columns and beams, each bay back-to-front → scaffold → pipe rack → barrow → jib, hook and hanging beam last (they overhang everything) → live layer (swing, welding spark).
  • Strokes only for the parcel boundary. Flat polygons and ellipses; no gradients.

Reuse

  • Copy the <svg> block plus the two @keyframes. For a static board tile drop the animations.
  • On a grid tile: <g transform="translate(TX,TY) scale(S) translate(-410,-250)"> — same wrapper as every stage; the crane will overhang the cell above, which is intended.
  • To animate progress, raise column height 0 → 120, then draw beams level by level, then lower the hanging beam into its bay.
